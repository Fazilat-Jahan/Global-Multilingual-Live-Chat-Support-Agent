Acme Co. — Loader Script Demo

This page embeds the support chat widget using the distributable /widget-loader.js — the same pattern a real client site would use. The loader is served from the widget host itself and creates a sandboxed iframe, launcher button, and responsive mobile mode automatically.

Waiting for postMessage events…

Verification checklist: (1) iframe has sandbox="allow-scripts allow-same-origin allow-forms allow-popups", allow="clipboard-write", and a src ending in /widget?tenant=default. (2) Launcher button (bottom-right) opens/closes the iframe. (3) Clicking the widget's internal close button (header ✕) posts a close message that hides the iframe and restores the launcher. (4) "Simulate foreign-origin postMessage" dispatches a forged message from a different origin — the loader's origin guard must ignore it. (5) Below 768px viewport the iframe expands full-screen with a close overlay. (6) curl -sI http://localhost:3000/widget shows Content-Security-Policy: frame-ancestors 'self' http://localhost:3000.
